# Restyle Filter Search Fields

## Goal

Improve the styling of search fields inside filter accordions.

## Context

The current search fields are too large and feel awkward inside the filter list layout. They should feel more integrated with the list controls.

## Notes

- Consider making search fields full width within the filter list/content area.
- Reduce height so they feel less dominant.
- Keep the styling theme-driven with existing MUI/local CSS patterns.
- Avoid hardcoded colors.
- Applies to decades, language, and culture filter search fields.

## Acceptance Criteria

- Filter search fields feel proportional to list items.
- Search fields align cleanly with surrounding filter content.
- Styling works in desktop and mobile filter layouts.
