# Collapse All Filter Accordions

## Goal

Add a "Collapse All" control next to the `Name Filters` heading in the filter drawer.

## Desired Behavior

- The control should collapse all open filter accordions at once.
- Existing individual accordion open/close behavior should keep working.
- The control should live visually next to `Name Filters`, not as a separate drawer action.

## Affected Area

- Filter drawer
- Name filter accordion state and controls

## Notes

- Preserve existing component patterns and styling conventions.
- Use theme variables only for colors and future theme compatibility.
- Do not introduce a new UI pattern without review.
