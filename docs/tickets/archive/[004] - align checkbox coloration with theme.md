# Align Checkbox Coloration with Theme

## Context

Filter checkboxes currently use the default icon coloration. They should probably follow the active theme more intentionally.

## Future Goal

Explore checkbox colors for checked and unchecked states so they feel on-theme without becoming visually heavy.

## Notes

- Primary at about 20% opacity may be a good starting point.
- Confirm whether checked, unchecked, hover, and disabled states need separate tokens.
- Use theme variables only.
- Preserve existing filter selection behavior.
