# Document Current Name Generator And Filter Drawer Behavior

## Requirements Reference

- `docs/application-requirements.md`
- `docs/current-name-generator-and-filter-drawer.md`

## Goal

Document the current name generator and filter drawer behavior before redesigning the unified workspace and filter experience.

## Context

The filter drawer is likely to change dramatically when the approved-name list moves out of the drawer and into the main workspace. Before redesigning it, capture how it works today so future changes are intentional.

## Scope

- Document the current desktop filter drawer structure.
- Document the current mobile filter behavior.
- Document the current approved-name list behavior inside the drawer.
- Document current filter sections:
  - gender
  - decades
  - languages
  - cultures
- Document search behavior inside nested filter sections.
- Document URL/filter synchronization behavior.
- Document tutorial touchpoints connected to the drawer and filters.
- Identify parts that feel opaque, complicated, or redundant.

## Acceptance Criteria

- A current-state document exists for name generator and filter drawer behavior.
- The document distinguishes desktop and mobile behavior.
- The document calls out how approved names currently appear in the drawer.
- The document identifies redesign pressure created by moving approved names into the main workspace.
- No implementation changes are made as part of this ticket.

## Documentation Notes

- Current-state documentation has been added at `docs/current-name-generator-and-filter-drawer.md`.
- This ticket should remain implementation-free.
