# Add themed sidebar background

After the name generator polish, revisit the filter drawer/sidebar background.

The original design direction may have called for the sidebar to use a non-background color. Explore a lighter primary shade so the drawer feels more intentionally themed while staying subtle in light mode.

Constraints:
- Use theme variables only; do not hardcode colors in component CSS.
- Prefer an existing token if one fits.
- If a new token is needed, add it to the theme variable layer rather than one-off component styles.
- Keep the main content background clean so the generator remains the focal area.
