# Improve Loading Page

## Goal

Replace the current plain "loading" text with a polished loading state.

## Notes

- Baseline MVP can be a centered loading spinner.

## Acceptance Criteria

- Loading state feels intentional and centered.
- Styling works in light mode.
- Implementation follows existing frontend component patterns.
