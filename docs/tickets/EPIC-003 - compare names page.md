# EPIC-003 - Compare Names Page

## Goal

Build the name comparison flow where saved names can be evaluated against each other.

## Notes

- The page should support selected names, comparison actions, remaining names, and return navigation.
- The design references include an `OR` comparison treatment and vote/history concepts.
- This likely depends on a stronger saved names screen first.

## Candidate Child Tickets

- Build compare page layout.
- Add selected-name pair display.
- Add compare/vote interaction.
- Add remaining-name options.
- Add return-to-list action.
- Add history/result presentation.
