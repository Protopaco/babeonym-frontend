# EPIC-004 - Create Account Modal

## Goal

Create a reusable account creation modal for moments where the app asks users to save progress or unlock account-backed behavior.

## Notes

- The modal should be reusable from generator, saved names, and future CTA flows.
- It should preserve the current workflow and avoid interrupting core name generation too aggressively.
- Auth provider choices and copy may need product decisions.

## Candidate Child Tickets

- Build create-account modal shell.
- Add provider sign-in actions.
- Add close/dismiss behavior.
- Add responsive modal styling.
- Wire modal to the first account CTA trigger.
