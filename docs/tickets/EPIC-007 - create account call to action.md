# EPIC-007 - Create Account Call To Action

## Goal

Add account creation prompts at meaningful moments in the product without derailing the core name flow.

## Notes

- The design references include account creation prompts around progress or approval milestones.
- This should be coordinated with the create-account modal epic.
- CTA timing and copy need to feel helpful, not pushy.

## Candidate Child Tickets

- Define CTA trigger moments.
- Add milestone CTA on the generator flow.
- Add saved-name persistence CTA.
- Connect CTA to create-account modal.
- Add dismissal or reminder behavior.
