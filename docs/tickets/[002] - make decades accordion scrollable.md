# Make Decades Accordion Scrollable

## Goal

Make the Decades accordion content scrollable so it does not make the filter drawer too tall.

## Desired Behavior

- Limit the visible Decades accordion content to roughly 5-6 decade rows.
- Additional decade options should scroll inside the accordion content.
- The accordion header and other filter controls should remain usable and visually stable.

## Affected Area

- Decades filter accordion
- Filter drawer styling

## Notes

- Preserve current filter functionality.
- Use theme variables only for colors and future theme compatibility.
- Prefer existing CSS/component patterns over adding new abstractions.
